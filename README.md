# 🎮 Tic-Tac-Toe 

A classic, interactive Tic-Tac-Toe game built from scratch. This project was developed to solidify core front-end development concepts, particularly DOM manipulation, event handling, and conditional game logic using vanilla JavaScript.

**[Play the Live Game Here](https://mohitt-ppandey.github.io/Tic-Tac-toe-game/)**

## ✨ Features
* **Interactive Gameplay:** Fully functional turn-based mechanics for two players (X and O).
* **Win & Draw Detection:** Built-in algorithm to immediately detect winning combinations or a tie state.
* **Responsive Design:** Clean and accessible user interface that scales across different screen sizes.
* **State Reset:** Easy restart functionality to clear the board without refreshing the page.

## 🛠️ Technologies Used
* **HTML5:** Semantic structure for the game board.
* **CSS3:** Custom styling, grid layout, and interactive hover effects.
* **JavaScript (Vanilla):** Game state management, event listeners, and victory logic.

## 🚀 How to Run Locally
If you want to run this project on your local machine:
1. Clone the repository: `git clone https://github.com/Mohitt-ppandey/Tic-Tac-toe-game.git`
2. Navigate to the project folder.
3. Open the `index.html` file directly in any modern web browser.
